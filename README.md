## Задания с IF

### Задание 1. Проверка числа

Пользователь вводит число. С помощью условного оператора определяется, является число положительным, отрицательным или равным нулю.

```javascript
if (number > 0) {
	alert('Число положительное')
} else if (number < 0) {
	alert('Число отрицательное')
} else {
	alert('Число равно нулю')
}
```

### Задание 2. Проверка возраста

Пользователь вводит свой возраст. Корректным считается значение от 0 до 120 лет.

Для объединения двух условий используется логический оператор `&&`.

```javascript
if (age >= 0 && age <= 120) {
	alert('Возраст введен корректно')
} else {
	alert('Возраст введен некорректно')
}
```

### Задание 3. Модуль числа

Пользователь вводит число. Если оно отрицательное, знак числа изменяется на противоположный.

Например:

```text
7  → 7
-7 → 7
```

### Задание 4. Проверка времени

Пользователь вводит часы, минуты и секунды.

Программа проверяет следующие диапазоны:

- часы — от 0 до 23;
- минуты — от 0 до 59;
- секунды — от 0 до 59.

Если все значения находятся в допустимых диапазонах, время считается корректным.

### Задание 5. Координаты точки

Пользователь вводит координаты `x` и `y`.

Программа определяет, в какой четверти системы координат расположена точка.

Также учитываются отдельные случаи:

- точка находится на оси X;
- точка находится на оси Y;
- точка находится в начале координат.

## Задания со SWITCH

### Задание 1. Номер месяца

Пользователь вводит номер месяца от 1 до 12.

С помощью конструкции `switch` программа выводит название соответствующего месяца.

Например:

```text
1  → Январь
5  → Май
12 → Декабрь
```

Если введено другое значение, выводится сообщение о том, что такого месяца не существует.

### Задание 2. Калькулятор

Пользователь вводит два числа и знак математической операции.

Поддерживаются операции:

```text
+
-
*
/
```

Выбор необходимого действия выполняется с помощью `switch`.

При операции деления дополнительно выполняется проверка деления на ноль.

## Задания с тернарным оператором

### Задание 1. Большее число

Пользователь вводит два числа. С помощью тернарного оператора определяется большее из них.

```javascript
let maxNumber = num1 > num2 ? num1 : num2
```

### Задание 2. Кратность пяти

Пользователь вводит число. С помощью оператора `%` определяется, делится ли число на 5 без остатка.

Проверка выполняется тернарным оператором:

```javascript
let multipleResult =
	multipleNumber % 5 === 0 ? 'Число кратно 5' : 'Число не кратно 5'
```

### Задание 3. Название планеты

Пользователь вводит название планеты.

Если введено `Земля` или `земля`, программа выводит:

```text
Привет, землянин!
```

В остальных случаях:

```text
Привет, инопланетянин!
```

Для выбора сообщения используется тернарный оператор.
